<p>批量采购和零售是两种生意：零售看单价，批量看批次质量、替换效率与管理能力。这篇讲清批量采购的四个阶段，给出议价与验收的具体做法，然后是池子的入库标准，最后是长期合作的维护方式。</p>
<h2>一、四个阶段</h2>
<p>阶段一，需求确认：几个地区、多少段、什么类型、用多久。阶段二，小批试用：三到五段，跑检测与稳定性。阶段三，批量下单：分批开通，边用边验。</p>
<p>阶段四，入库与养护：编号、绑定、巡检、替换。四个阶段缺一个，批量采购就会变成一堆难管的地址。</p>

<h2>二、议价怎么做</h2>
<p>筹码有三个：数量、长约、打包地区。数量翻倍能谈到两成折扣；长约半年以上再谈一到两成；多地区打包比分散采购便宜。</p>
<p>不要砍质量条款。把独享砍成半独享、把替换时限砍掉，省下的钱会在账号上还回去。要砍就砍初装费与服务费。</p>
<h3>报价怎么比</h3>
<p>统一到三个口径再比：每段每月多少钱、带宽多少、替换时限多久。三项对齐后，价格才有可比性。只看总价，容易被低配方案吸引。</p>
<h2>三、验收标准</h2>
<p>抽检两成：查 ASN、查 rDNS、查黑名单、测出口漂移。四项都过，整批签收。抽检不合格比例超过两成，要求整批更换。</p>
<p>稳定性要单独测：连续三天，每小时记录一次出口。漂移次数超过两次的段，退回。</p>

<h2>四、入库标准</h2>
<p>入库要满足三条：编号唯一、绑定明确、状态标记（在用、备用、停用）。三条不满足的地址，不进入池子，避免污染台账。</p>
<p>入库后立刻跑一次全量检测，作为基线。以后每次检测都与基线对比，才能看出变化趋势。</p>
<h3>长期合作怎么维护</h3>
<p>每季度复盘一次：用了多少、坏了多少、替换是否及时。复盘结果决定下一季度是加量还是换供应商。</p>
<h2>五、批量采购的五个坑</h2>
<p>批量采购的问题往往不在价格，而在批次质量与后续管理。下面五项是踩得最多的，逐条对照可以避开大部分损失。</p>

<p>五个坑的共同点是前期省事、后期费事。批量采购的价值在于规模效率，规模效率的前提是管理跟得上。</p>
<h2>六、批次采购的节奏怎么定</h2>
<p>一次性买满看着省事，实际是把风险集中。地址会坏，业务会变，买多了闲置，买少了不够用。合理节奏是先买计划的六七成，用满一个月再按实际使用率补。</p>
<p>补货时优先要同段或邻近段，管理成本低。跨太多 ASN 会让台账变得复杂，排查时也更费劲。补货的数量按上月的替换次数加一成估，比按感觉估准。</p>
<p>如果业务处在扩张期，可以把补货周期缩短到两周一次。小步快跑的好处是每次都能根据实际数据调整，不至于一次押错方向。</p>
<h2>常见问答</h2>
<h3>批量买能便宜多少？</h3>
<p>答：通常两到三成，取决于数量与长约。再低就要怀疑配置缩水。</p>
<h3>能只买地址不要服务吗？</h3>
<p>答：部分服务方支持，价格更低，但替换与支持要自己承担。</p>
<h3>一次买多少合适？</h3>
<p>答：先买计划的六到七成，跑一个月再补。一次买满容易积压。</p>
<h3>批次质量不稳定怎么办？</h3>
<p>答：合同里写清抽检不合格比例与处理方式，按条款执行。</p>
